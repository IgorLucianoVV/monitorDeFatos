    Como ler as checagens

    ✓ Verdadeiro
    As fontes confirmam. Arredondamentos razoáveis são aceitos.
    ≈ Impreciso
    Tem base real, mas o número, o período ou o contexto está distorcido.
    ✕ Falso
    As fontes contradizem a afirmação.
    ? Sem evidência
    Não há dados confiáveis suficientes para concluir.

    Toda checagem usa só fontes oficiais, científicas, agências de notícias e checadores reconhecidos. Se nenhuma fonte sustentar o veredito, ele vira “Sem evidência”. Confira as fontes antes de divulgar.

    Atalhos

    • 1–9 escolher quem está falando (transcrição sem oradores automáticos)
    • ? abrir esta ajuda
    • Esc fechar janelas
    • Clique numa checagem para ver o trecho da fala; num arquivo, o vídeo volta para esse momento.
